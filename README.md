# ⭐ Star Surface Modeling – SOLIDWORKS

A beginner-friendly **surface modeling project**
This project focuses on learning and practicing basic **surface modeling tools and techniques** by creating a star-shaped model.

## 📌 Project Overview

The model was created to understand how different surface modeling features can be combined to create a complex shape.

The main features used in this project are:

- Filled Surface
- Trim Surface
- Planar Surface
- Mirror
- Knit Surface



## 🎯 Learning Objectives

Through this project, I practiced:

- Creating surfaces from sketches
- Using **Filled Surface** to create closed surface regions
- Using **Trim Surface** to remove unwanted portions
- Creating surfaces using **Planar Surface**
- Using **Mirror** to reproduce symmetric geometry
- Combining surfaces using **Knit Surface**
- Understanding the basic workflow of SOLIDWORKS surface modeling
